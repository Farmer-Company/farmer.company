# Farmer.Company Product Docs

This folder is the working documentation set for the Farmer.Company beta.

## Purpose

These documents translate the current business model into an industry-standard product package that product, design, engineering, operations, and founders can use together.

## Folder Structure

- `PRD/`
  - Core product requirements, scope, metrics, and launch criteria.
- `UI_UX/`
  - Experience principles and device-specific UX guidance for both low-tech farmers and enterprise buyers.
- `To_Develop/`
  - Recommended features, technical improvements, and bug-fix backlog not yet started.
- `In_Progress/`
  - Workstreams that should start immediately for beta readiness.
- `Archive/`
  - Deprecated or superseded docs.
